基于 GitHub 基础版本 49bf84d 重新集成。控制模块放在现有 sd_card_bmp.v 中，工程源文件清单无须增加新条目。
顶层新增 key_mode，映射开发板 KEY3/B1（依据之前核验的开发板手册第19页）。

功能：普通图仅在扫描索引0、1、2之间切换；KEY3切换固定索引3应急图。

加载途中切换模式时，允许本次写入安全结束，但不提交已失效的画面。
KEY1复位，KEY2手动切图，KEY4自动轮播。音频保持基础例程测试音频。

## 上板验收

TF卡保留四张正确格式图片。下载本阶段bit后：
1. KEY2应只循环普通三张，KEY4打开/关闭自动轮播。
2. KEY3应显示第四张应急图；应急时KEY2/KEY4不起作用。
3. 再按KEY3恢复进入前普通图，原自动开关状态保持。
4. 长按KEY3只切换一次；加载期间重复进入/退出最终能恢复普通图。
5. 测试音频仍正常。

扫描器按TF卡物理扇区顺序识别BMP，并非文件名顺序。如果应急键显示的不是红色应急页面，应先检查素材在TF卡的实际扫描顺序。

# 第三阶段：应急音频联动

从已验收标签v0.2-emergency-validated开始修改。

普通模式发送静音PCM，应急模式产生880Hz/660Hz交替方波提示音，每个音约0.25秒，左右声道同源。
模式信号经两级寄存器同步到音频时钟域，音频源在采样边界处理静音与重新启动。
静音时保持I2S时钟及有效样本流，HDMI ACR计算继续运行。
画面控制、数码管诊断与TF素材顺序保持已验收版本。

ModelSim仿真使用实际I2S_receiver解码。6项检查通过：普通静音且持续有效采样、应急产生音频、采样包含正负值、退出静音且保持节拍、再次进入恢复音频、复位静音。

## 验收

1. 下载后普通模式三张图片展示正常，扬声器没有原例程音阶。
2. KEY3进入应急图片并持续播放双音提示；KEY2和KEY4仍被屏蔽。
3. KEY3退出后停止声音，恢复进入前普通图片与轮播状态。
4. 再次进入/退出、KEY1复位均符合上述行为。

提示音是合成音，不是语音播报。此次无须修改TF卡文件。

# 阶段4：时序与稳定性

基于v0.3-emergency-audio-validated修改。

## 修改

SDRAM控制及移相时钟由125MHz改为41.666667MHz（24ns周期、180度移相）；SD卡100MHz、视频25MHz、HDMI串行125MHz、音频时钟保持。
PLL的Verilog、VHDL与IPC配置同步修改。global_def.v刷新周期计算同步为24ns，防止降低时钟后刷新间隔变长。
理论32位SDRAM带宽约166.7MB/s，VGA有效像素读取约73.1MB/s；实际吞吐还受刷新、突发与仲裁开销影响，须上板检查。

SDRAM写应答增加两级同步再送BMP读取状态机。应答保持至请求撤销，该同步增加延迟但不缩短握手。
仅对已存在或新增的同步器第一级设置定向false path：写应答、帧完成toggle、音频模式、只读诊断向量。第二级正常计时；未屏蔽SDRAM数据读写路径。
继承基础工程原有视频/串行时钟与音频相关约束，当前报告结论限于这些约束及厂商模型。

## TD验证

TD6.2.1完整综合、布局、布线、bit生成完成。
最终Setup WNS=+0.271ns，Setup TNS=0；Hold WNS=+0.003ns，Hold TNS=0；Period Check WNS=0。
STA覆盖率99.97%，报告无建立或保持时间违例；不等于所有外部接口时序已经完成独立签核。
报告副本：releases/phase4-timing/timing_report.txt。
下载文件：releases/phase4-timing/anshibo_timing.bit。

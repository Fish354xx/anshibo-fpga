# 阶段5：独立图层与动态字幕

在阶段4已获用户确认的工程上增加campus_osd。模块附于已有video_rgb_to_axis_640x480.v，无须更改TD源文件清单。

顶部显示“安视播 | 普通模式/应急模式 | 运行 HH:MM:SS”。计时来自25MHz像素时钟，是运行时长，不是当前日期时间，复位清零、99小时后循环。
底部中文滚动标语“校园信息发布 文明校园 安全同行 按KEY3进入或退出应急提示”，每两帧向左移动一像素，完整周期1024像素含空白区。
字形16×16，45个字符，ROM1024×16bit。生成脚本tools/generate_osd.py使用Windows微软雅黑；生成结果已直接保存到Verilog，不需要运行脚本才能编译。
字幕区域采用背景亮度约四分之一的半透明底条，普通白字、应急金色字。
模式与计时在帧边界更新，像素数据、DE和VS统一延迟一拍，不改变背景图片控制及音频链路。

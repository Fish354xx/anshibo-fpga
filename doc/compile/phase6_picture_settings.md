# 阶段6实现与验证记录

## 实现

picture_key_control在已有sd_card_bmp.v内实现消抖后的长短按识别，避免工程漏加源码。普通短按在释放时触发，长按不触发短按动作，同时按键抑制释放动作。
亮度偏置为-64、-32、0、32、64；对比度以128为中心采用0.5、0.75、1、1.25、1.5倍，RGB各通道饱和到0～255。默认参数保持原像素。
参数在25MHz视频域经过两级同步并在帧边界锁存，叠加文字不参与颜色调整。应急模式强制使用默认颜色参数。
暂停轮播保留原自动状态；应急优先级不变。

发现既有display_valid信号直接从100MHz域控制RGB，在增加颜色处理后出现Setup -1.177ns；修复为视频域两级同步，仅第一同步级添加定向时序例外。未放宽颜色处理路径约束。

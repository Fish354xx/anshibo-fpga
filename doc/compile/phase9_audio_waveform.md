# 阶段9：音频波形叠加

## 实现

从现有I2S_receiver的video_clk域audio_valid和audio_left_data采样，直接复用HDMI输入数据，不增加异步采样总线或修改音源/I2S/音频封包。
audio_wave_snapshot使用双缓冲，隐藏银行连续采集128点，完成后等待帧边界公布，显示银行在一帧内不改写。两份相同小RAM提供当前点及前一点的同步读取，绘制阶跃处垂直连线。
取24位有符号音频的高8位映射到y=374附近，裁剪至340～408。实际±2000000音源约产生上下30像素幅度，静音为中央平线。采样时间窗约128/48000=2.67ms，每个视频帧至多更新一次，不宣称持续无损采集或频谱分析。
面板x64～575、y332～417，标签“音频波形”在y310～325；半透明背景、坐标网格、边框、绿色普通波形/金黄色应急波形。RGB、DE、VS和RAM读取仍一像素对齐，不改现有视频时序。
tools/generate_osd.py可重新生成61字中文ROM及新模块，均包含在已注册TD源文件内。保留已上板通过的阶段8限速与背压。

# 阶段6：亮度与对比度实时调节

下载本目录 anshibo_picture_settings.bit，PROGRAM_SRAM / 5MHz，TF素材不变。

普通模式短按KEY2切图、短按KEY4轮播开关；短按操作在松开并消抖后触发。
长按KEY4约1秒进入/退出调节模式。调节时短按KEY2增加、短按KEY4减少；长按KEY2切换亮度/对比度。
两个参数均0～4档，默认2档。调节期间暂停轮播，退出后恢复原先轮播状态。
KEY3随时进入应急模式并退出调节，用户参数保留，应急图采用原始亮度/对比度；再次KEY3返回普通显示。
KEY1复位后参数恢复2档。

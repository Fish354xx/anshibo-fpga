# 安视播独立源代码包

安视播：基于HX4S20C的HDMI校园多媒体展示系统。

## 编译

解压到英文目录，用Anlogic TD6.2.1打开src/td_project/anshibo.al。器件EG4S20BG256，顶层top，开发板HX4S20C。保留目录关系后执行综合、布局布线及Generate Bitstream。项目根Path改为相对路径“.”，其余工程设置保留。已集成字幕拨码控制、首图优先加载、应急音画启动同步及SW2/SW3调节控制。全部工程引用已检查，

## 目录

src：TD工程、RTL、官方加密IP、IP配置及约束。
tb：仿真测试平台。
sim：ModelSim脚本；先将各脚本$simulatorDir改为本机路径，默认D:\FPGA\modelsim_ase\win32aloem。
tools：OSD及测试图片生成脚本，需Python和Pillow，默认Windows微软雅黑字体；编译现有RTL无需运行这些脚本。
SOURCE_GUIDE.md：阅读索引。
SOURCE_ORIGIN.md：来源与修改范围。
tools/build_td.tcl：独立目录完整编译脚本，从src/td_project目录调用TD命令行执行。

## 使用与限制

TF卡按既有已验证方式准备，普通前三图、应急第四图；扫描前64MiB并按物理扇区排序，不是完整FAT文件系统读取。支持正高度RGB24非压缩BMP，宽1～1280、高1～960，最近邻缩放至640×480。

KEY2切图，KEY4轮播，KEY3应急及返回，KEY1复位。SW2拨上开启调节、拨下退出；SW3拨下选择亮度、拨上选择对比度。调节时KEY2增加、KEY4减少，进入调节会暂停轮播，退出后恢复。按键长按不切换调节模式或参数类型。应急模式屏蔽调节；退出应急后按SW2状态恢复调节。

音频PLL为12.295082MHz，理论采样率约48.028kHz；应急提示音由实际显示帧门控启动，实际采样精度未测量。转场淡出至黑再淡入，OSD计时是运行时长。

本包未包含bit、图片、编译输出、仿真库或Git历史。已移除无用备用例程及工程条目；保留实际编译依赖、官方IP及仿真文件。来源与修改范围见SOURCE_ORIGIN.md。

官方.enc.v和厂商IP保留原版权标识，内部实现不属于本项目自行编写部分；使用和再分发遵循原提供方许可，本包未对厂商文件另授开源许可。

## SW1叠加显示控制

SW1拨上：显示图片、文字和音频波形；拨下：只显示图片，去掉所有OSD文字及背景条和波形面板。声音仍由应急模式控制。官方HX4S20手册第18页：SW1=C8，上为1、下为0。输入两级同步并稳定20ms后在下一帧边界更新，运行计时和波形采样在隐藏时继续。复位期间默认显示，随后采纳SW1状态。最新位流见提交目录firmware/anshibo_final.bit。

## 首图优先启动

启动时校验并跳过FAT32元数据区，找到首图即加载显示，再继续扫描余图。完整扫描结束后才接受切图和应急操作。具体限制、仿真和上板步骤见STARTUP_OPTIMIZATION.md。

## 应急音画启动同步

提示音等待应急图片提交及实际读缓存匹配，于应急帧首个有效像素开始时启用；退出应急及时静音。图片读取期间保持静音，SW1不控制声音。实现、限制与验证见EMERGENCY_AV_SYNC.md。

# 安视播：校园电子广告牌与分级应急发布

独立工程，以remote-subtitles已保存版本为基线。日常海报、图片轮播、普通TEXT通知、转场、画面调节、HDMI音频链路和波形保留，不包含电子班牌或分区发布功能。

本阶段实现三级预警、本地选择确认、长按紧急、本地后台等级仲裁及不同声光表现。预警正文为固定模板，后台事件包、事件编号、动态应急文字和活动视频播放尚未实现。

## 三级内部演示配置

| 等级 | 画面 | 音频 |
|---|---|---|
| 一级提醒 | 日常图片继续播放，增加提醒条，普通通知继续滚动 | 静音 |
| 二级警戒 | 独立警戒页面及行动指引，日常图片暂停 | 约每秒短响一次（约0.2秒），固定880Hz |
| 三级紧急 | 第四张应急图片、红色等级标题及疏散指引 | 880Hz与660Hz交替持续报警 |

内部等级不是官方灾害预警等级。二三级主画面等待应急缓存与实际读帧编号匹配，音频门控与显示等级在对应帧的首个有效像素启动。二三级提示不能被SW1/OVERLAY隐藏。解除或降级到一级后，等待普通缓存恢复再退出主预警页，报警门控及时关闭。

## 本地操作

- KEY3短按并松开：打开预警选择。尚无预警时默认一级，有预警时默认“解除本地预警”。
- 选择中KEY2：依次切换解除、一级、二级、三级；此时不切换图片。
- KEY3再次短按并松开：确认所选本地等级。
- KEY3长按约2秒：直接发布本地三级；松开不会再次进入选择。
- 选择界面10秒无操作：取消待选项，不修改已经生效的等级。
- 正常状态KEY2下一张、KEY4轮播及SW2/SW3参数调节沿用。

本地和后台等级分别保存，实际等级取两者较高值。解除本地只清除本地记录；若后台仍有预警，画面会继续预警。后台清除同样不会清除本地记录。

## 串口测试

PROGRAM_SRAM下载firmware/anshibo_graded_alert.bit，下载列表仅保留这一文件。TF四张图片无需更换。退出旧串口窗口，启动本目录tools/launch_uart.cmd，连接现有COM端口。

```
ALERT 1
ALERT 2
ALERT 3
ALERT CLEAR
STATUS
TEXT 校园通知：请保持教室卫生
```

每条等待应答，再观察显示/声音后继续。ALERT CLEAR只清除后台记录。原EMERGENCY ON/OFF兼容为后台三级/后台清除。普通TEXT只更新日常通知，不能覆盖预警正文。

STATUS增加E实际仲裁等级、B本地等级、M后台等级。E是逻辑请求状态，不是已完成显示回执；主画面和恢复还可能等待TF及缓存就绪。OK只表示接受指令。

RESET为维护用整机复位，清除两方易失记录；它不是预警业务解除命令。串口断开不会自动清除已发布等级；断电或复位后记录清零。当前二三级依赖已有第四张应急BMP和TF初始化完成；缺卡情况下的独立应急画面留待后续实现。

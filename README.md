# 安视播独立比赛工程

基于已经上板验证的官方 lab_ex5_i2s 例程建立。

## 当前阶段

建立独立工程并复现官方图片切换、自动轮播和 HDMI 测试音。尚未添加作品功能。

## 开发环境

- Tang Dynasty 6.2.1
- HX4S20C / EG4S20BG256
- 顶层模块：top
- 工程入口：src/td_project/anshibo.al
- HDMI接口：HDMI_B

## 使用

用 TD 打开 anshibo 工程入口（实际文件名为 anshibo.al），重新执行完整编译，再下载本工程生成的 bit 文件。使用已经验证的 TF 卡图片和接线，确认手动切图、自动轮播及测试音。

## 来源与基线

源代码、IP及引脚/时序约束保留官方例程内容；工程路径和名称调整为独立目录。编译缓存不继承，需重新生成。baseline_check.json 记录文件引用检查。

后续每次只实现一个阶段的功能，并在上板确认后继续。

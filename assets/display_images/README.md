# 显示素材

四张图片使用内置 imagegen 生成，再转换为 640×480、RGB24、无压缩 BMP。公告时间与应急提示均为演示内容。

TF卡仅复制 0_welcome.bmp、1_notice.bmp、2_safety.bmp、3_emergency.bmp；PNG用于预览，original PNG用于保存高清原稿。

提示词主题：欢迎页（安视播、校园音画联动信息发布系统、基于安路 EG4S20 FPGA）；公告页（实验室周一至周五09:00—17:00开放，遵守管理规定，演示内容）；安全页（关闭电源、禁止私接电线、异常及时报告，演示内容）；应急页（演示模式、保持冷静、听从现场工作人员指引、仅用于项目演示）。统一4:3画幅，清晰大字，蓝青校园科技风，应急页红白配色，无水印。

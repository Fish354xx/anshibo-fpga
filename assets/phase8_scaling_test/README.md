# 阶段8上板测试素材

以下四个文件已经是RGB24、无压缩、从底向上存储的BMP。图中标有原始尺寸及目标输出尺寸；网格、白色边框和四角色块便于检查是否错行或裁剪。

按下表顺序逐个复制到空的FAT32 TF卡根目录：

| 次序 | 文件 | 用途 |
|---|---|---|
| 0 | 00_welcome_320x240.bmp | 安视播，小图放大 |
| 1 | 01_notice_1280x960.bmp | 校园公告，大图缩小 |
| 2 | 02_safety_641x481.bmp | 安全提醒，非整数缩放且每行1字节填充 |
| 3 | 03_emergency_640x480.bmp | 应急提示，原尺寸 |

现有读取器按原始扇区扫描，不能按文件名排序，也不能处理碎片化文件。仅删除原文件后复制新图可能扫描到旧BMP残留。先将TF卡原内容完整备份到电脑，再确认盘符并将这张TF卡重新格式化为FAT32，然后依次复制四个BMP（不需要复制本说明）。
比赛正式素材在assets/display_images中，恢复时同样使用空FAT32卡按0、1、2、3顺序复制。

上板前先用原TF卡测试新程序，确认原640x480素材仍正常；然后换上述测试素材。
